إهداء | Ehda2 — حزمة الموقع
=============================
الرابط بعد النشر على GitHub Pages:
  https://kareemhakeem1.github.io/ehda2/           الصفحة الرئيسية
  https://kareemhakeem1.github.io/ehda2/studio/    استوديو الدعوات
  https://kareemhakeem1.github.io/ehda2/cards/     برقيات وبطاقات التهنئة
  https://kareemhakeem1.github.io/ehda2/i/sample/  دعوة العينة

خطوات النشر (على الكمبيوتر أسهل):
  1) فك الضغط عن الملف، هتلاقي ملفات ومجلدات (studio, cards, i, index.html ...).
  2) github.com > New repository > الاسم: ehda2 > Public > Create repository.
  3) اضغط "uploading an existing file" واسحب كل اللي جوه المجلد (الملفات والمجلدات، مش ملف zip) > Commit changes.
  4) Settings > Pages > Source: Deploy from a branch > Branch: main و /(root) > Save.
  5) استنى دقيقة أو اتنين، وافتح الرابط اللي بيظهر فوق في صفحة Pages.

ملاحظات:
  - الريبو العام معناه إن أي حد يقدر يتصفح ملفاته على GitHub، فما ترفعش عليه دعوات العملاء النهائية.
  - غيّر الدومين لاحقاً: اشتري دومين واربطه من Settings > Pages > Custom domain، وقولّي الدومين وأعيد بناء الحزمة.
  - دعوات العملاء النهائية: على استضافة بدون ريبو عام، مجلد لكل عميل باسم عشوائي.
